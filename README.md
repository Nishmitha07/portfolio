## 📌 Featured Projects

Bluetooth-controlled smart pet feeder built using Arduino and HC-05 Bluetooth module.

**Technologies**
- Arduino
- Embedded C
- HC-05 Bluetooth

---

### 🌱 Smart Automatic Compost Bin
IoT-based composting system that monitors moisture, temperature, and chamber levels using ESP32 and multiple sensors.

**Technologies**
- ESP32
- Arduino
- IoT
- Sensors

Implementation of instruction-aware fine-grained clock gating for an open-source RISC-V processor to reduce dynamic power consumption.
